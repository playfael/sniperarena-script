# MNZS | Sniper Arena

SA 0.7.

Cole esta linha no executor:

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/playfael/sniperarena-script/main/SniperArena.luau"))()
```

**RightShift** abre e oculta o menu. As opções, atalhos e seleções de skins são salvos localmente pelo script.

`SniperArena.luau` contém o script completo, incluindo as imagens dos temas. `integrity.json` identifica os bytes desta publicação.
